# zhyx1996.github.io

Personal homepage based on GitHub Pages, built with AI assistance.

## Pages

- `index.html` Homepage (profile / articles / Steam / Sakana widget)
- `projects.html` Repos · `stars.html` Stars · `articles.html` Blog
- `gomoku.html` Gomoku (Rapfi AI, WASM multithreading)
- `gomoku-godot/` Gomoku Godot build
- `nethack.html` NetHack

## Tech

Vanilla HTML / CSS / JS, no build; GitHub API integration; responsive layout.

## Local Preview

```bash
python -m http.server 8000
```

Visit `http://localhost:8000`.

## Deployment

Auto-published by GitHub Pages after pushing to `main`.
